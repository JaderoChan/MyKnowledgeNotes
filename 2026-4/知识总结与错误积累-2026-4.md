# 知识总结与错误积累-2026-4

## 26-10-19

1. **Qt** `QPlainTextEdit` 相比 `QTextEdit` 对于纯文本/大文档的性能更好。
2. **Qt** `QLayout::addStretch(0);` 详解：

    `addStretch(int stretch = 0)` 的参数是伸缩因子（stretch factor），表示该伸缩项在分配剩余空间时的权重比例。伸缩因子为 0 时表示该项不参与剩余空间的按比例分配，但它的 `sizeHint` 和 `minimumSize` 仍然会被考虑，但作为“弹簧”的作用几乎消失。

    如果布局中所有项伸缩因子都是 0，那么所有项按各自的 `sizeHint` 分配空间，多余的空白由布局的对齐/边距处理，`addStretch(0)` 不会主动“撑开”。

    总体而言：`addStretch(0)` 本身权重为 0，但作为 `QSpacerItem` 它仍具有扩展倾向，在没有其他竞争者时能吸收多余空间；一旦有 `addStretch(1)` 存在，它就被完全压制。

3. **Qt** `QLineEdit::setText()` 会绕过 `QValidator`，直接设置文本内容。
4. **Qt** `QValidator::validate()` 函数的第二个参数 `int& pos` 代表当前光标在字符串中的位置，其是引用类型，这意味着函数可以更改用户的光标位置以允许验证器在修正输入时同步调整光标位置。
5. **Qt** `QVariant` 的 `isValid()` 函数与 `isNull()` 并不等价

    **核心差异**

    | 函数 | 判断的是什么 | 返回 true 的条件 |
    | --- | --- | --- |
    | `isValid()` | 是否有类型 | 存储的类型不是 `QMetaType::UnknownType` |
    | `isNull()` | 是否没值 | 没有初始化值，或包含空指针 |

6. **Qt** `QFontMetries::horizontalAdvance()` 返回的是从当前文本原点开始，到绘制下一个字符的合适起始位置之间的距离（以像素为单位）。

    `horizontalAdvance()` 返回的是“排版推进距离”，用于排版，当需要把多段文本并排摆放时，可以用这个值来决定下一段文本从哪开始画；`boundingRect().width()` 返回的是“墨迹覆盖范围”，用于获取文本实际渲染出来的像素包围盒。。

    **注意事项**

    对于阿拉伯字符或字符串中间的非间距标记，`horizontalAdvance()` 会给出错误结果，因为它无法处理复杂文本的字形整形（Shaping）。如果需要实现交互式文本控件，官方建议使用 `QTextLayout`。

7. **Qt** `QtTreeView::setIndexWidget()` 设置的 Widget 不会覆盖 Item 的图标部分，它会浮动在单元格内，从图标右侧开始显示。
8. **Qt** 通过 `appendRow()` 将 Item 加入 Model 后，Model 会接管 Item 的所有权，也就是说，如果通过 `removeRow()` 删除了某行 Item，不需要再手动释放其内存。

## 26-10-21

1. **C/C++** C++ 的 `static_cast` 与 C 风格强转区别：

    | 特性 | `static_cast` | C 语言强转 |
    | --- | --- | --- |
    | 编译期检查 | 有，检查类型兼容性 | 几乎无 |
    | 类型安全 | 较高，限制在合理转换内 | 较低，易导致未定义行为 |
    | const 移除 | 不可以 | 可以 |
    | 无关指针转换 | 不可以 | 可以 |
    | 可读性与可搜索性 | 高 | 低 |
    | 本质 | 受限的、语义明确的转换 | 万能的、意图模糊的兜底方案 |

2. **C++** 的结构化绑定总是声明新变量，无法直接使用已有变量，例如：

    ```cpp
    bool ok;
    int  value;
    {
        auto [ok, value] = getResult(); // 此处的 ok、value 并非外层已有变量，而是将外层变量命名遮蔽的新变量。
    }
    ```

    如果需要直接赋值给已有变量可以使用 `std::tie`，例如：

    ```cpp
    #include <tuple> // 必要头文件

    bool ok;
    int  value;
    {
        std::tie(ok, value) = getResult();
    }
    ```

    `std::tie` 会把左值引用打包成 `tuple`，再对 `pair/tuple` 做逐元素赋值。
